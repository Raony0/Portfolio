# Portfólio — Raony Janelato

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — estrutura e conteúdo
- `style.css` — identidade visual, layout e responsividade
- `script.js` — menu mobile, animações de entrada e ano automático

## Antes de publicar

Edite no `index.html`:

1. Link do LinkedIn
2. Seu e-mail

## Estética

A identidade combina uma estética **dark editorial + streetwear/tech**, com tipografia forte,
monoespaçada, bastante espaço negativo e verde ácido como cor de destaque.


## Projeto em destaque

O portfólio utiliza atualmente a **SLY Company V2** como projeto principal, com JavaScript aplicado a catálogo dinâmico, filtros, modal de produtos, carrinho e LocalStorage.
